## PENALIDADES POR FALTA DE REQUISITOS

### Se Usar Item SEM a Perícia Mínima:

| Diferença | Penalidade |
|-----------|------------|
| 1 nível abaixo | -1 em todos os testes com o item |
| 2 níveis abaixo | -2 em todos os testes |
| 3+ níveis abaixo | -4 em todos os testes (praticamente inutilizável) |

**Exemplo:**
- Jogador tem Perícia Espada 11
- Tenta usar Espada T5 (requer Perícia 14)
- Diferença: 3 níveis
- Penalidade: **-3 em todos os ataques** com essa espada

---

### Se Usar Armadura Pesada SEM a ST Mínima:

| Diferença | Penalidade |
|-----------|------------|
| 1 ST abaixo | -1 DX para todos os testes |
| 2 ST abaixo | -2 DX, Deslocamento -1 |
| 3+ ST abaixo | -3 DX, Deslocamento -2, Fadiga dupla |

**Exemplo:**
- Jogador tem ST 11
- Tenta usar Armadura de Placas T5 (requer ST 14)
- Diferença: 3 ST
- Penalidade: **-3 DX, -2 Deslocamento, Fadiga em dobro**

## DICAS DE PROGRESSÃO

✅ **Não pule Tiers.** Vá de T3 → T4 → T5 gradualmente.  
✅ **Sempre tenha um set reserva** no tier anterior guardado no armazém.  
✅ **Priorize arma > armadura** para DPS, ou **armadura > arma** para tanks.  
✅ **Items .1 e .2 valem o investimento.** Pequenos bônus fazem diferença.  
✅ **Nunca use seu único set T8 em expedição arriscada.** Morte = perda total.
