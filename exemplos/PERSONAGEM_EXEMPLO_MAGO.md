## TÁTICAS DE JOGO

**Papel no Grupo:** DPS Mágico / Controle de Área  

**Rotação de Combate:**
1. **Posicionar-se atrás do tank**, distância segura (15-20m).
2. Usar **Escudo de Chamas** [Peito] se houver risco de ser atacada.
3. Spam de **Seta de Fogo** [Q] (custo 0 FP com Economia de Mana!).
4. Usar **Parede de Chamas** [W] para bloquear corredores ou separar adds.
5. Guardar **Meteoro** [E] para fases críticas do boss (abaixo de 30% HP).

**Gestão de FP:**
- **Seta de Fogo** é grátis graças a Economia de Mana. Abuse!
- Sempre manter 6 FP para o Meteoro de emergência.
- Usar Poções de Energia quando FP cair abaixo de 50%.

**Posicionamento é TUDO:**
- Nunca ficar perto de corpo a corpo.
- Sempre ter rota de fuga.
- Usar terreno elevado quando possível (+1 para acertar).
